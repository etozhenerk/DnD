# Бэкенд

Go API проекта «Хроники Восьми Земель». Пока это каркас без БД, авторизации и интеграции с AI Studio. Единственный маршрут — `GET /health`, описанный в [`shared/api/openapi.yaml`](../shared/api/openapi.yaml).

```bash
go test ./...
go run ./cmd/api
```

Сервер слушает порт `8080`; его можно изменить переменной окружения `PORT`.
