# Видеовставки навыков героев — Grok Video

## Общие настройки

- Поверхность: Grok Imagine, image-to-video.
- Формат: 16:9, 1080p, 6 секунд.
- Звук: отключить, generate_audio=false.
- В игре: воспроизведение x2, итоговая длительность около 3 секунд.
- Для каждого ролика загружать только указанный стартовый кадр.
- Все результаты бросков оставлять неразрешёнными: ролик показывает применение, а не подменяет механику.
