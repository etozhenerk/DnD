# Рабочий пакет кампании «Мальчишник конца света»

Идентификатор кампании: `penisuela`. Машинный источник текущего состояния — `workflow.json`; этот файл служит кратким индексом.

## Что утверждено

- концепция и обновлённый сюжетный каркас;
- сюжетный граф из 26 узлов, в котором обе семейные ветки сходятся перед встречей с Егориком;
- обновлённые паспорта Стаса, Полины и Олвы;
- полный сценарий из 26 сцен, включая семейную развилку и два исхода парной сессии;
- диалоговый банк из 108 мастерских пресетов;
- формальные механики всех 26 сцен, включая две взаимоисключающие награды и три семейных эпилоговых модификатора;
- взаимоисключающие ветки семейного крыла: Вуманайзер с Павильоном 18+ либо бескровная парная сессия Стаса, Полины и Олвы;
- два исхода парной сессии: развод ради свободы Стаса либо добровольное продолжение семейного плана Полины;
- 17 кампанийных портретов, десять опубликованных сценических кадров, утверждённая VIP-реквизиторская и финальный тизер.

Утверждённые арты опубликованы в `assets/concepts/campaigns/penisuela/` и зарегистрированы в `assets/concepts/manifest.json`. Локальные генерации в `art-drafts/` и папка личных референсов исключены из Git и не являются зависимостями кампании.
