# Укрытие Крида — целевая проверка 2026-09-07

Статус: подключение сцены проверено; полная кампания этой проверкой не принимается.

## Изменение

Утверждённый v8 (`groom-hideout.png`) подключён к встрече, признанию и двум существующим последующим экранам, ранее использовавшим тот же старый арт. Для коридора и двери это временный общий фон: отдельные арты ещё предстоит согласовать.

Новый канонический факт: Крид увидел нападение призванных стражей на людей и бунгало, спрятался в бункере и опасается преследования. Он свободен и сразу говорит. Встреча не требует спасения, d20, ресурсов, урона или Doom. Дальнейший существующий переход из признания сохраняет Doom +1 за продвижение сюжета.

В короне: «Поговорить с Кридом» → признание; «Идти с Кридом» → следующий маршрут. Публичное описание — общий SceneTextPanel с appearance="narration", фиксированным «Рассказчик» и readAloud. Добавлена привязка команд LateStoryAdventure к sceneScopeId и отмена текущей сцены в короне на затронутых экранах.

Стабильные scene/action ids и флаг kreed-rescued сохранены. Старые частично завершённые rescue-группы не блокируют разговор. Ранее записанные последствия в пользовательском журнале не стираются.

## Изменённые области

- Канонические preview, gameplay, dialogue и guide Пенисуэлы.
- Рабочие script, story-graph, gameplay, dialogue, cast, art-plan и implementation-plan; сняты активные ссылки на отменённую ловушку.
- Виджет LateStoryAdventure; общие компоненты переиспользованы.

## Браузер

Codex in-app browser, локальный Vite 127.0.0.1:4176. Проверены 1280×720 и 1024×768, сделаны и просмотрены снимки в ходе проверки. Арт загрузился, текст помещается, лицо не закрыто панелью, заголовок только «Рассказчик». На 1024 scrollWidth = clientWidth = 1024; broken images = 0, console warn/error = 0.

Проверены корона, единственная кнопка разговора, непосредственный переход в признание, reload, переход к следующему маршруту. Тестовые команды отменены через общую консоль. Затем повторная команда с sceneScopeId отменена через «Шаг назад» исходной сцены; кнопка разговора снова доступна. Сохранение оставлено до разговора, viewport override снят. Шумный вариант покрыт данными/тестами прохода и синхронизацией текста; отдельный browser-проход шумного входа в этой проверке не повторялся.

## Ошибки вне этой встречи

- npm run test:penisuela-navigation падает на regex-проверке гостиничного выхода в HotelOverloadSearchAdventure: ожидается прежнее выражение из consoleAcquired, braceletsAcquired, pendantResolved, weatherResolved. Этот виджет и данная проверка в текущем изменении не правились.
- Валидатор рабочего story-graph сообщает `Conditional node has no fallback transition: groom-tunnel`. Единственный закрытый флагами выход тоннеля существовал до этой правки; runtime-проход и четыре финала успешно проверены playable smoke. Этот отдельный контракт валидатора требует согласования с текущим последовательным испытанием тоннеля.

Полный регресс всех остальных экранов, боёв, карты и книги героев не проводился. Commit, push и deployment не выполнялись.
