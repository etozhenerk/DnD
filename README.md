# Хроники Восьми Земель

Yandex Cloud временно отключается с 14 октября 2026. [Инструкция восстановления с нуля](docs/architecture/yandex-cloud-recovery.md) содержит настройки сервиса и порядок создания ресурсов. Тестовые данные не сохраняются.

Репозиторий сервиса авторских D&D-кампаний. Сейчас игрокам доступен статический фронтенд; Go-бэкенд реализует конструктор персонажей и Советника.

| Каталог | Назначение |
| --- | --- |
| [`frontend/`](frontend/README.md) | React-приложение, ассеты, сборка и фронтовые проверки |
| [`backend/`](backend/README.md) | Go API конструктора и Советника |
| [`shared/`](shared/README.md) | Общая YAML-спецификация HTTP API |
| [`content/`](content/README.md) | Канонический лор, правила, герои и кампании |
| [`skills/`](skills/) | Общие локальные инструкции для работы с проектом |
| [`docs/`](docs/) | Продуктовые планы, сценарная работа и исследования |
| [`infra/`](infra/) | Конфигурации облака и экспериментальных LLM-ВМ |

Фронтенд запускается из своего каталога:

```bash
cd frontend
npm ci
npm run dev
```

Бэкенд запускается отдельно:

```bash
cd backend
go test ./...
go run ./cmd/api
```

GitHub Actions собирают и проверяют код. Деплой Yandex Cloud приостановлен до восстановления инфраструктуры; GitHub Pages независим от него. Подробности запуска и архитектуры находятся в README соответствующих каталогов.
