# Пульт: первый аудиотрек и номера кнопок — 11 сентября 2026

Статус: passed-scoped. Актуальная начальная позиция видео — 6 секунд по последней правке пользователя. Этот отчёт дополняет dance-video-2026-09-11.md.

## Изменение

Первая кнопка подключена к `assets/concepts/campaigns/penisuela/audio/dance-track-01.mp3`: скачанный пользователем MP3 Todrick Hall — Nails, Hair, Hips, Heels. Аудиопоток сохранён без перекодирования, обложка и метаданные удалены. Файл зарегистрирован в manifest как `penisuela-dance-track-01-audio` и указан в `dancePuzzle.tracks[0].audio.source`.

Пульт показывает «Трек 1», «Трек 2», «Трек 3»; названия и описания песен скрыты и на кнопках, и в строке выбора. Видео увеличено, кнопки расположены справа тремя рядами. Пагинация скрыта, если треки помещаются на одной странице. Встроенные controls аудио позволяют остановить песню и изменить громкость. Выбор другого трека без source останавливает предыдущее аудио. Правильный ответ, последствия ошибок и отдельное подтверждение решения не менялись.

Новое необязательное поле `dancePuzzle.video.startSeconds` описано в content/README.md и модели GalleryVideoSlotDefinition. Значение 6 применяется при loadedmetadata, каждом выборе трека и ended (пока петля активна); нативный loop используется только при нулевом смещении. Аудио всегда начинается с нуля. Сценарий мастера синхронизирован.

## Проверки

- `npm run build` (включает typecheck) и `npm run build:pages` — успешно; стандартное предупреждение Vite о крупных chunks.
- JSON, уникальность ID ассета, существование source и неизменность correct у дорожек — проверены.
- Браузер: реальный MP3 воспроизводится, paused=false, muted=false, readyState=4, duration=236.190499; видео остаётся muted=true.
- Повторный клик по первой кнопке перезапускает оба потока. При проверке механизма со смещением 5 получены video=5.198224 и audio=0.005009; финальная правка меняет только параметр на 6, механизм тот же.
- Выбор второго трека удаляет аудиоэлемент, музыка останавливается; повторное открытие пульта запускает только немое видео.
- Скриншоты 1280×800 и 1024×768: новый пульт проверен, горизонтального переполнения нет. Старые названия не присутствуют в DOM пульта. Ошибок консоли нет. Скриншоты приложены в ходе задачи, отдельные PNG не сохранялись.
