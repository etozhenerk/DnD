## Дополнение: общая панель мастера и последовательный undo

- Устранена общая причина двух одинаковых кнопок: наличие обработчика полного перезапуска больше не создаёт вторую кнопку локального перезапуска. В баре отображаются «Начать прохождение заново» и «Шаг назад» без дубля.
- На сценах с отдельным локальным сбросом сохранены две разные команды: «Начать прохождение заново» и «Начать сцену заново».
- Быстрая панель и полная GM-консоль вынесены из изолированного слоя сцены, поэтому остаются кликабельными поверх обязательного `SceneDecisionModal`.
- Во встроенном браузере пройден точный регрессионный путь: неверный трек → модалка → бой → «Шаг назад» → восстановленная модалка → «Шаг назад» → полностью снятый выбор трека.
- Тот же откат из восстановленной модалки подтверждён кнопкой «Отменить последнее действие» в полной GM-консоли.
- На контрольном viewport `1280×720`, DPR `2`, scale `1` горизонтального переполнения нет; ошибок и предупреждений browser console нет.
- `npm run test:session`, `npm run test:npc`, `npm run test:penisuela`, `npm run build` и `npm run build:pages` прошли. Pure reducer-тест отдельно фиксирует возможность продолжить undo после отмены команды старта боя.
