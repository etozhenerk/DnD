# Корона: две постоянные команды

Запрос автора: остановить переработку большой GM-консоли; исправить дубли навигации во всей игре.

## Исправление

- `SceneMasterControl` больше не принимает `onStart` / `startLabel`. Постоянная группа содержит ровно «В начало сцены» и «Шаг назад». Недоступная команда остаётся видимой, но выключенной.
- Из `CampaignScene` и всех использовавших его адаптеров удалены `masterStartLabel` / `onMasterRestart`. Полный сброс кампании и выход в соседнюю локацию больше не подменяют начало сцены. Начало использует существующий снимок блока.
- Пролог использует ту же пару команд. «Следующий кадр» остаётся действием пролога.
- Удалены отдельные возвраты из короны Стаса, танцоров, музыкального пульта и аудиенций; удалены переходы от награды Алексиса напрямую к другим NPC.
- У Олвы убраны отдельные выход, возврат к разговору и отмена действия из короны. В комнате остаётся «Рассмотреть стол» / «Посмотреть решение»; за столом дополнительных навигационных команд в короне нет.
- `olvaMasterStepBack.ts` объединяет контекстную навигацию и отмену изменений. Отмена принятого исхода возвращает к голосованию; отмена голоса и раскладки не закрывает соответствующий рабочий экран.

## Проверки

- `npm run typecheck`, `npm run build` — успешно.
- `npm run test:regression` — 29/29 наборов. Добавлен `test-crown-navigation.ts`; старые проверки, требовавшие отдельные кнопки возврата, заменены проверками единой навигации и сохранённых выходов на арте.
- Встроенный браузер: отдельное сохранение на `127.0.0.1:4181`; пользовательская вкладка `4176` не изменялась.
- Проверены короны всех 27 действующих маршрутов, пролога, поиска в номере и трёх внутренних экранов бара. Состояния с пропуском Олвы и входом к Егорику проверены после получения допуска через интерфейс.
- Дополнительно: корона в бою у Егорика; отмена начала боя. Неверный трек → бой → шаг назад → предложение боя → шаг назад → снова доступен выбор трека.
- Стол Олвы: комната, стол, улика, голосование, принятый исход. Отмена переноса, голоса и принятого исхода через единственную команду «Шаг назад».
- «В начало сцены»: поиск → пробуждение; Алексис → холл; танцоры → бар; голосование Олвы → развилка бунгало; укрытие Kreed → тоннель; распаковка → вход на виллу. Все шесть переходов подтверждены в браузере; восстановление данных снимка покрывается существующими тестами checkpoints.
- Визуальная проверка: 1280×800 и 1024×768. Горизонтального переполнения и ошибок консоли нет.

Это проверка короны и затронутой навигации, а не новая полная приёмка всех боевых исходов. Переработка большой GM-консоли остановлена и не объявляется завершённой. Сюжет, награды и арты не менялись.
