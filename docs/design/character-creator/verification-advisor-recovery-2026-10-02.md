# Проверка восстановления диалога Советника

Дата: 2 октября 2026. Локальные сборки и автоматические тесты не запускались.
Проверка встроенным браузером Codex, фактический viewport 1280×720.

## Исправленные причины

- Неопределённая попытка навсегда занимала сессию и блокировала дальнейшие сообщения.
  Миграция 000009 ограничивает уникальность только текущим `reserved`.
  Неизвестный расход остаётся зарезервированным, прежний UUID не генерируется повторно.
- Анкета могла не уложиться в 22 секунды. Генерация текста теперь допускает 60 секунд,
  полный сценарий — 70, frontend — 75; короткие комментарии сохранили прежние пределы.
- Обычный чат возвращал лишь текст. Теперь `propose_character` отдаёт проверенную
  анкету, а `generate_character_image` — отдельное поручение рисования со стабильным UUID.
  Только отправка выполняет поручение; чтение истории и открытие модалки не генерируют.
- Композер очищался после успешного ответа. Он теперь очищается при отправке,
  неизменяемая попытка для явного повтора хранится отдельно.
- Шапка модалки могла сдвинуться при переходе к кнопке внутри истории: `overflow: clip`
  оставляет прокрутку только во внутренних областях.

## Реальный сценарий

В `http://127.0.0.1:4173/characters/new/appearance`, использующем облачный API:

1. Реплика «Заполни все поля» с задумкой Тарена Листопляса вернула полную анкету:
   эльф, плут, все шесть разделов, один активный навык и два обычных предмета.
2. Карточка показала утверждённые характеристики, 34 HP и 13 AC; применение заполнило форму.
3. В той же сессии следующая реплика получила совет о привычке героя с учётом предыстории.
4. Текстовая просьба нарисовать героя вызвала инструмент и отдельную генерацию изображения.
5. Изображение показало героя целиком, с головой, ногами и обувью; выбранный вариант
   добавился в галерею. Исходный JPEG 832×1280, кадр не обрезался обработкой.
6. Поле ввода осталось пустым после каждой отправки, снова доступно по завершении.
   Enter отправляет; дальнейший диалог не блокируется.
7. Горизонтального переполнения нет, шапка после прокрутки на y=48, `dialog.scrollTop=0`.

Запас после четырёх вызовов — 97%: верхняя граница дополнительного расхода 6 ₽.
Предыдущая проверка чат/fill/портрет/иконка стоила 6,1195 ₽; общий предел 20 ₽ соблюдён.
Герой применён только в памяти frontend, в production PostgreSQL не сохранён.

Снимок: `/private/tmp/dnd-advisor-chat-full-body.png`.
Ошибки HMR в журнале вкладки до 15:56 UTC относятся к предыдущим правкам; в выполненном
сценарии новых ошибок не обнаружено. Другие страницы и мобильная компоновка не менялись.
