# Видео музыкального пульта — 11 сентября 2026

Статус: passed-scoped. Локальный выбранный ролик воспроизводится; прежний блокер внешнего источника устранён. Это проверка медиаплеера, не повторная приёмка всей кампании.

## Результат

Пользователь предоставил и утвердил клип Todrick Hall — Nails, Hair, Hips, Heels. Канонический файл: `assets/concepts/campaigns/penisuela/videos/closed-bar-dancers.mp4`, зарегистрирован как `penisuela-closed-bar-dancers-video` в manifest и подключён через `dancePuzzle.video.source`. Внешний CDN больше не используется.

H.264, 1920×1080, 264.765 секунды, 75 712 660 байт. Видеопоток перенесён без перекодирования; аудиопоток удалён, метаданные очищены, moov перенесён в начало (faststart). Исходный пользовательский файл не изменён. Тяжёлый исходник не добавлялся отдельно.

Существующий DanceTrackConsole воспроизводит MP4 через source, с autoplay, muted, playsInline и без controls. Каждый клик по доступной песне возвращает видео на нулевую секунду и продолжает воспроизведение. Повторный клик по той же песне также работает. Решение загадки остаётся отдельной кнопкой, loop сохраняется до освобождения труппы. Сценарий мастера синхронизирован. Новых сюжетных фактов, миграций и изменений игрового движка нет.
