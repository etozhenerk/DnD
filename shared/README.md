# Общие контракты

[`api/openapi.yaml`](api/openapi.yaml) — источник истины для HTTP-контракта между фронтендом и Go-бэкендом. Здесь хранятся спецификации, а не общий TypeScript-код. Создаваемые по спецификации файлы должны находиться внутри соответствующего проекта.

`api/proposals/` содержит YAML-предложения со статусом `draft`. Они не меняют действующий API. [Навыки конструктора v1](api/proposals/character-abilities-v1.yaml) обсуждаются вместе с [правилами и примерами](../docs/architecture/character-abilities-v1/gameplay-notes.md); перенос в основной контракт выполняется после утверждения.
