# Управление Yandex Cloud

1. Прочитать `AGENTS.md` и документацию затронутого ресурса в `docs/architecture/`. Проверить активный каталог, текущие ресурсы и состояние операции перед изменением.
2. Проверять актуальный синтаксис и ограничения по официальной документации Yandex Cloud и `yc --help`. Для платного ресурса оценить месячную стоимость и её место в общем бюджете до создания.
3. Для изменений использовать `yc` либо консоль Yandex Cloud. Не считать отправленную операцию завершённой: дождаться итогового статуса и проверить созданный ресурс.
4. Выдавать минимальные IAM-права и сетевой доступ, достаточные для задачи. Секреты держать в Lockbox или другом утверждённом хранилище; не выводить значения в лог, документацию, Git или фронтенд.
5. Записать стабильные идентификаторы, конфигурацию, стоимость и шаги подключения в соответствующий документ `docs/architecture/`. Зафиксировать фактический результат, ограничения и ресурсы, которые продолжают тарифицироваться.

Создание и изменение облачных ресурсов требует авторизации в задаче; сам скилл её не предоставляет. Не удалять работающие ресурсы и не расширять доступ ради диагностики без необходимости.
