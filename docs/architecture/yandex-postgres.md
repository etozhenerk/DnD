У хоста нет публичного IP. Go API размещён в Serverless Containers и подключается к той же VPC. Группа БД принимает TCP 6432 из служебного диапазона Serverless `198.19.0.0/16` (правило `enpg07v4p3m9bdq5lpdm`); это приватный доступ внутри сети проекта. Старое правило от группы `dnd-api-db-client` сохранено для будущего клиента на ВМ, такой ВМ сейчас нет. У клиентской группы разрешено исходящее TCP 6432 только к группе БД.

Пароль пользователя создан Yandex Cloud автоматически и хранится в Connection Manager / Lockbox. Значение секрета не записывается в Git, в документацию или в переменные фронтенда. Для подключения Go-сервиса нужно получить его через разрешённый механизм секретов и включить TLS. Адрес хоста и порт `6432` относятся только к внутренней сети.

Автоматические резервные копии запускаются с 22:00 UTC, хранятся 7 дней. Обслуживание назначено на вторник, 01:00–02:00 UTC. Защита от удаления включена. Единственный хост может быть временно недоступен во время обслуживания или сбоя; второй хост и репликация пока не заказаны.

Консоль оценивала конфигурацию одного хоста `c4a-c2-m4` с SSD 20 ГБ в **4 480,70 ₽ в месяц** на момент создания. Это оценка при непрерывной работе, без скидок, изменения тарифов и возможного роста хранилища. [Правила тарификации](https://yandex.cloud/ru/docs/managed-postgresql/pricing) описывают оплату хостов, диска и резервных копий. Для этого кластера автоматическое увеличение диска не задано.

После операции WebSQL отключён; операция `c9q1sfmeh1k36tvrgjv0` завершилась без ошибки. WebSQL включается только на время административных операций. Канонические шесть героев не переносятся автоматически.
