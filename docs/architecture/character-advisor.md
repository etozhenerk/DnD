# Советник конструктора персонажей

## Первый шаг: бесплатные подсказки

Добавлены общий каталог [`shared/advisor/guide.json`](../../shared/advisor/guide.json),
характер совы в [`persona.md`](../../shared/advisor/persona.md) и публичный
`GET /creator/advisor`. Чтение не создаёт сессию, не сохраняет анкету и не вызывает AI.
Каталог загружается при старте Go API из `ADVISOR_GUIDE_PATH`; Docker и CI включают файл.
API возвращает политику бюджета и фактические возможности, с кэшем процесса на пять минут.

Фронт использует тот же каталог из сборки: переход на этап не ждёт сеть.
Светлое облачко с одной короткой фразой появляется над совой с хвостиком к её голове. Реплика доступна
как `status` для экранного диктора, внутри нет кнопок. Смена текста не двигает
сову и кнопку чата: под сцену зарезервирована высота. Reduced motion отключает
анимацию появления и приветствия.

Сова — находчивый пернатый сообщник, который обращается на «ты», иногда шутит
и помогает выбрать. Она не запрещает необычные имена и не навязывает билд.
Каталог и инструкция не добавляют новых персонажей или фактов в канон мира.

## Место для диалога

Под увеличенной совой находится кнопка «Поговорить с совой». Она открывает
большое модальное окно: история занимает отдельную область с прокруткой,
поле сообщения и отправка находятся снизу. Окно закрывается крестиком,
Escape или кликом вне него; фокус возвращается на кнопку. Фоновая страница
недоступна для взаимодействия, пока открыт диалог. Будущая история будет
общей для всего процесса создания и не должна очищаться при закрытии окна.

На десктопе правая колонка начинается под шапкой приложения; лента этапов
занимает только ширину формы и не отнимает высоту у советника. Подписи этапов
контрастные, без тёмной прямоугольной подложки. Убраны отдельное затемнение
вокруг портрета и нижний декоративный кант. Мобильное взаимодействие отложено
по решению пользователя: плавающая
сова и нижняя панель не включаются; отдельную компоновку будем проектировать позже.

Ввод и отправка включаются по `capabilities.chat` из API. До подключения облачной
интеграции виден статус подготовки; платных запросов интерфейс не делает.
Приветственный жест использует исходный арт и CSS; кадры моргания, размышления
и других состояний совы ещё предстоит подготовить.

## Следующий шаг: сессия и AI Studio

- Одна роль советника с режимами диалога, короткого комментария и предложения
  заполнить поля. Генерация изображений — отдельный инструмент этой роли.
- Инициативный комментарий — только реплика в облачке. Его текст попадёт в
  историю чата, чтобы игрок мог продолжить тему. Не показывать устаревший ответ
  после смены имени, класса или этапа; не запускать LLM на каждую клавишу.
- Сессия советника отделена от анкеты и будущего авторизованного черновика.
  Непредсказуемый токен хранится в памяти текущего конструктора; в БД — хэш,
  срок действия, история диалога и журнал расходов. Анкета остаётся в памяти
  фронта, её текущий снимок передаётся как контекст запроса, без автосохранения.
- Сначала модель получает только публичный лор и серверные каталоги правил.
  Ответ не меняет поля автоматически. Для заполнения нужен структурированный
  результат, проверка баланса сервером и просмотр игроком перед применением.
- Лимит **200 ₽ на сессию создания** включает сообщения, автоматические
  комментарии, изображения и повторы. Серверная реализация ограничения подготовлена; платный режим остаётся выключен
  до применения SQL и настройки IAM.
- Перед платным запросом резервировать его максимальную стоимость транзакцией
  в PostgreSQL; после ответа учитывать фактическое usage. Повтор с тем же
  request ID не создаёт второй вызов. Неясный исход по таймауту сохраняет резерв.
  Дополнительно нужны общий месячный предел и ограничения частоты: без входа
  лимит сессии нельзя надёжно превратить в лимит на человека.
- Режим создания по фотографии исключён из текущего плана по решению пользователя.
  Обычная генерация портрета и иконок по тексту остаётся следующим этапом после чата.

Существующие `/drafts/*` по-прежнему закрыты до авторизации. IAM-доступ AI Studio,
платные генерации и миграции сессий на этом шаге не включались.

## Реализованный второй шаг: диалог и журнал расходов

Код подготовлен 2 октября 2026 года. Cloud IAM, SQL и платная конфигурация пока не
менялись. Предложенный общий бюджет **10 000 ₽/мес** утверждён пользователем.

### HTTP и интерфейс

Три отдельные операции: начать сессию, прочитать её и отправить сообщение.
[Контракт 0.8](../../shared/api/openapi.yaml) задаёт обязательные поля и ошибки.
История живёт в PostgreSQL, а её секрет — в памяти конструктора. Закрытие модального
окна не сбрасывает беседу; выход из конструктора очищает frontend-кэш сессии.
Перезагрузка страницы теряет секрет. Новая сессия не объявляет игрока владельцем героя.

TanStack Query читает историю с отменой и без автоматического повторения ошибок.
Пока ход `reserved`, клиент проверяет его каждые 2 секунды. После неопределённой
отправки сохраняются её UUID и тело: повтор возможен только явно с тем же ID.
Подтверждённый ответ очищает поле. Enter отправляет, Shift+Enter переносит строку.
Поле остаётся в фокусе во время отправки. История прокручивается за ответом, пока
игрок не начал читать выше; повторное открытие не проигрывает старую печать заново.

Ответ появляется плавной анимацией на клиенте после получения целого JSON.
Это **не поток токенов провайдера**: время ожидания обозначается компактной репликой.
Reduced motion отключает печать. Поддержаны абзацы, заголовки, списки, жирный текст
и inline code; HTML, ссылки и изображения остаются текстом, не исполняются.

### Контекст и агент

Первая роль советника реализована на бэкенде поверх Chat Completions. Объект агента
в Agent Atelier пока не создаётся; управление инструментами и генерация изображений
появятся следующим этапом. Инструкция совы находится в `shared/advisor/persona.md`.

Публичные знания загружаются из канона при старте: каталог классов, рас и навыков;
из мировой карты передаются только ID, названия, подписи, описания земель и публичный
анонс `teaser.description`. Другие поля карты и файлы кампаний исключены явной проекцией.
Имя, выбранные раса/класс, этап и краткая задумка текущей анкеты передаются на один вызов.
Анкета в SQL не сохраняется. Текст сообщения и ответ хранятся как приватная беседа.
Модель видит до шести последних завершённых ходов в пределах 32 КиБ текста prompt;
её инструкция прямо сообщает о неполной истории. Сводку памяти и поиск по публичному
лору добавим отдельно. Числа в совете не заменяют серверную проверку готовой анкеты.

### SQL, лимиты и исходы

- `advisor_sessions`: хэш секрета, 24-часовой срок доступа, учтённая сумма.
- `advisor_turns`: текст реплики/ответа, хэш запроса, модель, reservation, usage,
  стоимость и исход `reserved` / `succeeded` / `uncertain`.
- `advisor_months`: общий расход и административная блокировка месяца.

Деньги — integer в миллионных долях рубля. Месяц считается в `Europe/Moscow`.
Резерв привязывается к месяцу начала запроса и не переносится при ответе в следующем.
SQL-блокировки и уникальный индекс сериализуют бюджеты и активный ход; транзакция
завершается до сетевого вызова AI, поэтому соединение БД не удерживается во время генерации.
Общее поступление ходов сериализуется также на границе месяца. Повтор UUID со старым
телом читает результат, с другим телом возвращает 409, новые ход и расход не создаются.

Принятые ограничения первой версии: 200 ₽/сессия, 10 000 ₽/месяц, 100 ходов/сессию,
один активный ход на сессию, шесть на сервис, 60 ходов/мин; новые сессии — 12/мин,
60 за последние 24 часа. Запросы истории и бесплатные подсказки LLM не вызывают.
Runtime-конкурентность подготовлена на 12 HTTP-запросов, чтобы чтения помещались рядом
с шестью генерациями; CPU/RAM и число подготовленных экземпляров сохраняются.

Цены закреплены вместе с `deepseek-v4-flash`: 0,3 ₽/1000 входных, 0,075 ₽/1000 кешированных,
0,5 ₽/1000 выходных токенов, включая НДС ([тариф](https://aistudio.yandex.ru/ru/docs/ai-studio/pricing),
проверен 02.10.2026). Рассуждения входят в `completion_tokens`; повторно не прибавляются.
`max_completion_tokens=4096` ограничивает видимый ответ и рассуждения
([API](https://aistudio.yandex.ru/en/docs/ai-studio/api/Chat-Completions/createChatCompletion)).

Резерв **31,8464 ₽** использует консервативную оценку входа: три токена на каждый
UTF-8 байт разрешённого текста плюс 1024 служебных токена и полный лимит выхода.
После получения корректного usage лишнее освобождается. Это резервная оценка;
совместимость модели и её фактического tokenizer envelope ещё предстоит подтвердить
живой проверкой. Первое включение выполняется в рамках приёмки с пробной репликой;
при несовместимости сразу возвращаем выключенное состояние. Стоимость в журнале
считается по закреплённым ценам и usage, её сверяем с облачным биллингом при смене тарифа.

При обрыве, таймауте или невозможности подтвердить usage резерв не освобождается.
Новый ход этой сессии блокируется до административной сверки; после двух минут
зависший `reserved` показывается как `uncertain`. Это правило защищает от второго
платного вызова. При нарушении оценённого token envelope блокируется весь месяц.
Автоматического повторения модели, возврата неизвестного расхода и фонового worker нет.
Учёт завершается синхронно с отдельным трёхсекундным cleanup даже при уходе браузера.

24 часа — срок доступа, **не срок удаления данных**. Автоматическая очистка истории
и сверка неизвестных исходов пока не реализованы; эти административные операции
нужно добавить до длительного публичного использования.

### Включение после разрешения на публикацию

1. Применить `000006_advisor_sessions` от `dnd_owner`, затем `000007_advisor_permissions`:
   `dnd_api` получает только SELECT/INSERT/UPDATE на три новые таблицы. Проверить версии,
   индексы и права, после операции выключить WebSQL.
2. Назначить runtime `dnd-api-runtime` (`aje99fiebjm3lg4k2fpk`) роль
   `ai.languageModels.user` на каталог `b1g8siv8ve2si1qp04nm`. Для этой текстовой интеграции
   [достаточна эта роль](https://aistudio.yandex.ru/ru/docs/ai-studio/api-ref/authentication).
   Ключи GitHub и постоянные API-ключи не создаются.
3. Опубликовать код через CI, сначала с `DND_ADVISOR_CHAT_ENABLED=false`. Дождаться тестов,
   проверить бесплатные подсказки и сохранение персонажей. SQL не исполняется CI.
4. Для приёмки включить variable `DND_ADVISOR_CHAT_ENABLED=true` и развернуть ревизию.
   Сразу отправить одну короткую неперсональную реплику через штатный журнал: проверить
   параметры модели, usage, длительность до 22 секунд, отключённое logging, резерв/списание
   и повтор UUID. При ошибке выключить variable и вернуть ревизию с платным режимом off.
5. Проверить HTTPS CORS, создание/чтение сессии, отказ чужому секрету, диалог из браузера,
   возврат из окна и сохранение готового героя. Отключение variable останавливает новые
   платные обращения после развёртывания ревизии, история и журнал сохраняются.

[URI модели](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models),
[заголовок отключения логирования](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/disable-logging).
