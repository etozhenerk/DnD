# Бунгало Егорика — целевая проверка, 7 сентября 2026

Scope: утверждённые входной и боевой арты, три призванных рунических стража, общий боевой интерфейс и продолжение в тоннель. Это приёмка эпизода, не всей кампании. Commit, push и deployment не выполнялись.

## Реализация

- Два PNG опубликованы без изменения композиции в `assets/concepts/campaigns/penisuela/scenes/egorik-bungalow-summoned-guards*.png` и зарегистрированы в manifest.
- `penisuela-session-preview.json` выбирает входной арт и interactionView `combat`. Отдельного зелёного прохода нет.
- `penisuela-gallery-gameplay.json` содержит отдельную встречу `egorik-bungalow-guards`, три уникальных unit ID, общий утверждённый token и действия всех пяти героев.
- `GuestBungalowsAdventure` передаёт единый контроллер с областью отмены текущей сцены в `EgorikBungalowAdventure`. Общий `SceneCombatPanel` подключает HUD, цифровые кубики и команды сессии.
- После победы общий итог боя сменяется рассказом пары. После поражения показывается рассказ о помощи Настасьи, без ложного заголовка «Победа». Кнопка тоннеля завершает и сохраняет исход перед переходом.
- Канонические диалоги и guide, рабочий script, implementation-plan и gameplay-notes синхронизированы для этого эпизода. Исторические технические ID исходов сохранены.

- `npm run validate:penisuela-playable`: PASS, 722 проверки.
- `npm run typecheck`, `npm run build`, `npm run build:pages`: PASS. Vite сообщает существующее предупреждение о крупных chunks.
- `jq empty`: PASS для затронутых JSON. Уникальность ID сцен, действий, встреч, пресетов и manifest проверена. Ссылки новой встречи, её unit/behavior, портрета и двух фонов разрешаются.
- Встроенный браузер: 1280×720 и 1024×768, скриншоты входа, боя и сюжетного итога просмотрены. Горизонтального переполнения нет: scrollWidth = clientWidth = 1280 / 1024; изображения загружены. На 1024×768 кнопка атаки находится внутри окна (нижняя граница 689 px).
- В отдельном тестовом сохранении пройден путь Олва → отказ от просьбы → пять пропусков → развилка → прямой вход. Бой у двери не запускается.
- Пройден бой до победы через физические значения d20 и кубиков урона: критические эффекты, HP, инициатива и второй раунд. Проверены цифровой d20, reload активного боя, подтверждение победы, разговор и переход в тоннель.
- Цифровой d20 вернул 1; «Принять результат» перенесло число в общий боевой HUD. Применён «Магический шёпот» Линды: на стража наложен резонанс ×2, ход передан следующему участнику, видео навыка воспроизвелось. Отмена вернула действие Линде и убрала эффект.
- Через общую консоль выставлены 0 HP пяти героям: аварийное продолжение восстановило каждого до 1 HP. Reload сохранил отдельный исход поражения; переход в тоннель работает.
- Последовательная отмена победного и проигранного прохождений возвращает входной арт, убирает результаты боя и сохраняет пропуска Олвы. Старое сохранение с завершённым спасением не требует повторного боя.

## Канон и ограничения

Новый факт по указанию автора: враждебный механизм призвал знакомых рунических стражей разрушать бунгало. Вода, мостик и насос удалены из исполняемого эпизода. Допущение реализации: при полном поражении Настасья отсекает призыв; партия восстанавливается до 1 HP и получает факты, но не союзную помощь. Числа встречи перенесены из охраны бара для пяти героев, урон меча физический.

Третий, послебоевой арт ещё не утверждён: рассказ показывается модально поверх затемнённого боевого фона. Исторические `docs/story-graph.json` и `docs/gameplay.json` остаются помечены устаревшими для этой сцены в art-plan; источником исполняемого сюжета служит `content/`.

Общая проверка ссылок обнаруживает прежние `rail-prop-kraken` в наборах combatActions при удалённой встрече. Эти ссылки не добавлены данной задачей; отдельная кампания целиком не объявляется прошедшей приёмку. При горячей замене кода браузер один раз сообщил об изменении длины зависимостей useEffect; это предупреждение Fast Refresh, проверка итогового кода выполнялась после перезагрузки.

Финальная чистая вкладка с итоговым кодом: ошибок и предупреждений консоли нет. Тестовая сессия возвращена на входной арт; временное ограничение viewport снято.
