# Финал титров: однократная песня и пауза благодарности

Изменение по просьбе автора: песня не должна повторно включаться в конце, строка «Спасибо» остаётся на пару секунд, после неё начинается ролик с рукой на драконе.

## Итоговое поведение

1. Песня играет один раз (`loop=false`). Если она закончилась до конца ленты, больше не запускается: `ended` блокирует повторные попытки через `canplay`, пользовательские жесты и обновления состояния. Явный новый просмотр титров по-прежнему начинает песню с нуля.
2. По окончании прокрутки звук останавливается. На чёрном фоне остаётся только «Спасибо за эту историю» на 2000 мс.
3. Затем тот же плеер начинает послетитровое видео. Благодарность убирается по фактическому событию `playing`; при ожидании загрузки она остаётся видимой. Новых кнопок и дополнительного пустого интервала нет.
4. Ролик играет целиком со своим звуком на скорости 1×. После окончания — чёрный экран, без повторной благодарности или песни.

## Изменённые области

- Feature `play-campaign-credits`: однократная песня, защита завершённого трека, уведомление о фактическом старте видео и очистка слушателя `playing`.
- Widget `CampaignCredits` / `CreditsPostlude`: строка благодарности перед видео и чёрный экран после него; локальные CSS Modules и существующие цветовые переменные.
- Канонические данные `penisuela-credits.json`: `postCreditsVideo.delayMs=2000`. В `content/README.md` уточнено назначение задержки; гайд, video-plan, production pack и workflow синхронизированы.
- Видео, музыкальный файл, 20 фотографий, персонажи, обе концовки и игровые механики не изменены. Состав партии — пять героев.

## Проверки

- `test-credits-music-handoff.ts`: проверена полная пауза 2000 мс на управляемых часах (на 1999 мс видео ещё не стартовало); естественно закончившаяся песня не запускается повторно; благодарность заменяется видео только по `playing`; повторные события не дублируют переход; отмена очищает таймер и слушатели; новый просмотр возвращает песню с начала без loop.
- `test-credits-music.ts`: проходят проверки восстановления первоначального autoplay, AbortError, переходов, остановки и поздних promise-результатов.

- `test-campaign-credits.ts`: обе концовки, канонические ассеты, пауза 2000 мс и громкость.
- `npm run typecheck`, `npm run build`, `npm run build:pages` — пройдено.
- `jq empty`, уникальность ID, связи концовок и согласованность времени/завершения в JSON, гайде, video-plan и workflow; `git diff --check` — пройдено.
