# Регресс Пенисуэлы — 9 сентября 2026

Статус: проверенные сценарии пройдены, найденные блокировки устранены. Область — текущая игра Пенисуэлы, 28 сюжетных экранов и дополнительный экран поиска утром. Другие кампании не входят в приёмку. По уточнению автора проверки внешних страниц прекращены, экспериментальные изменения книги героев отменены точечным патчем; прежние пользовательские изменения сохранены.

## Возврат и начало сцены

Каноническое `sceneBlocks` в `content/campaigns/penisuela-session-preview.json` задаёт шесть блоков:

| Блок | Экран начала | Внутренние взаимодействия |
| --- | --- | --- |
| Утро | hotel-overload | Пробуждение, поиск предметов |
| Холл | hotel-gallery | Алексис, Pussy Sultan, реквизиторская |
| Бар | closed-bar | Стас, танцоры, музыка и бой |
| Бунгало | guest-bungalows | Олва, стол улик, Егорик |
| Бункер | groom-tunnel | Препятствия и все экраны Kreed |
| Вилла | graywise-door-trust | Дверь, спальня, обмен, злодей, обе фазы и концовки |

«В начало сцены» возвращает экран входа и снимок прогресса при первом входе: предметы, ячейки, HP, заряды, флаги, Doom, бой, локальные состояния экранов и полученные награды. Повторное посещение не перезаписывает снимок. Сброс раннего блока удаляет контрольные точки более поздних блоков. Журнал сохраняется полностью; событие отката выбирает действующую ветку без удаления аудита.

Для старых сохранений без контрольных точек механическое состояние восстанавливается по журналу перед первым действием блока. Исторический порядок ручной раскладки и осмотров до появления снимков восстановить точно нельзя: интерфейс блока открывается с начала. Новые контрольные точки сохраняют эти данные точно. Стабильные ID и версия существующего журнала сохранены.

## Исправления

- Танцоры: отмена боя возвращает решение, следующая отмена снимает неверный выбор. Закрытие и повторное открытие устройства больше не возвращают застрявшую модалку. Есть явное возвращение к выбору трека.
- Общая модалка поддерживает действие без вызова обработчика закрытия: запуск боя больше не отменяет только что сделанный выбор.
- Переходы между экранами размонтируют локальный контроллер; смена подвида бара через query сохраняет нужное локальное состояние.
- У Kreed восстановлены предыдущие маршруты; уже использованные переходы доступны после возврата без повторной выдачи последствий.
- В бункере и у Grey Wiese «Назад» сначала закрывает незавершённую проверку; отмена очищает отложенный переход.
- На развилке бунгало «Назад» закрывает сообщение о запрете прохода.
- Сохранение инвентаря сохраняет существующие ячейки. Запись Егорика согласована между ID движка и видимого предмета, включая новые предметы и восстановление сохранения.
- Проём реквизиторской возвращает к Pussy Sultan по клику на изображение, с привязкой координат к cover-кадру. Рассказчик гостиничных экранов использует общий `readAloud`.
- Подсказка трёх жетонов исправлена в соответствии с действующей проверкой: нужны также два пропуска Алексиса.
- Контекст диалогового банка включает актуальные комнаты гостиницы. Реплики Pussy Sultan и Алексиса доступны внутри их блока без принудительного обхода контекста.
- Удалены неиспользуемые ссылки боевых действий на старую встречу с рельсовым кракеном; игровой JSON и зеркало синхронны. Числа баланса не менялись.

- `npm run typecheck`, `npm run build`, `npm run build:pages`: **PASS**. Сборщик сообщает о крупных chunks; это не ошибка выполнения.

Старые самостоятельные валидаторы сценарного графа/релиза содержат условия удалённого сюжета и не используются как критерий текущей игры. Новый `validate-penisuela-current-release.mjs` проверяет действующую проекцию канонических данных. Полный перебор всех численных комбинаций бросков в браузере не заявляется: развилки проходят сценарные тесты, UI проверен на перечисленных примерах. Мобильный интерфейс, другие кампании, публикация и изменение артов вне области задачи.
