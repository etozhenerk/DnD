# Проверка текущей Пенисуэлы

Дата: 14 сентября 2026. Статус: автоматические проверки пройдены; браузерное покрытие — по указанным ниже целевым приёмкам прошлых ревизий. Полная повторная визуальная приёмка и публикация не заявляются.

## Фактические проверки этой правки

| Команда | Результат |
|---|---|
| `npm run test:regression` | 38/38 наборов прошли |
| `npm run build` | прошла, включая оба TypeScript-проекта |
| `npm run build:pages` | прошла, включая TypeScript и base `/DnD/` |
| `node scripts/validate-penisuela-current-release.mjs` | 28 экранов + поиск, шесть блоков, пять героев, 10 встреч, 47 активных пресетов, 216 существующих ассетов; ссылки и зеркала сценария/gameplay совпадают |
| Валидатор `story-graph.json` | `Graph valid: 29 nodes, 1 starts, 2 endings, routes 142-158m` |
| Валидатор `combat-story-graph.json` | `Graph valid: 34 nodes, 1 starts, 2 endings, routes 118-118m` |

Веса времени унаследованы из старого графа и не включают все повторные визиты и реальную длительность боёв. Предупреждение о коротком пути 142 минуты ниже прежних рекомендуемых 150 не является проверкой игрового темпа. Vite сообщает о чанках более 500 kB; обе сборки завершаются успешно.

Исправлены два исходных сбоя: тест количества музыкальных вариантов и расхождение рабочего сценария с каноническими 12 песнями. Тест теперь требует ровно один правильный ответ и не менее двух разных неверных вариантов, проверяет вызов волны и запрет повторного подтверждения для каждого неверного трека. Ожидание HP VIP-охраны приведено к новой настройке 56 HP.

## Состав текущей игры

Семь действующих встреч, восемь боевых точек, две фазы Нетака. Три архивные встречи в каталоге не считаются отсутствующими сценами. `penisuela-final-boss.json` и старый `FinalBossAdventure` обслуживают прежний финал; действующий финал задаёт `gallery-gameplay.bossSequence` и `AndreyBossAdventure`.

Карточка отдыха, квест Оливии, пять иконок действий мобов, оба финала, 12 локальных песен и видео пульта реализованы. Сценарные условия и правила рунической охраны сохранены по прямому указанию автора.

Баланс ослаблен через HP примерно на 20%. Подробные результаты по 1–2 ошибкам, каждому герою, расходу ресурсов и разным решениям мастера — в [balance-review.md](balance-review.md). Условные тактические модели не являются гарантией результатов живой партии.

Сегодня UI, стили, медиа и обработчики проходов не менялись. Новая проверка браузера, мобильного режима, карты и книги героев не проводилась. Отсутствующие измерения не записываются как успешные. Известные большие чанки — технический долг, а не ошибка сборки.

Старый отчёт от 24 августа сохранён в [архиве](history/2026-09-14-before-tuning/release-verification.md); его 25 узлов, 40 экранов, 82 ассета и три фазы босса не описывают текущую игру.

Заключительная проверка: `jq empty` для изменённых JSON и `git diff --check` — PASS; 216/216 используемых путей найдены в manifest. Структурное сравнение с началом этой правки подтверждает ровно семь изменений канонического gameplay — только поля HP встреч. Механики, AC, действия, медиа и правила проходов не изменены.
