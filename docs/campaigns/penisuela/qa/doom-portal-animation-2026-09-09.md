# Анимации дума и портала Нетака

Добавлены только эффекты кампании. `CampaignPresentation` сохраняет презентацию между сменами экранов; исходный прогресс поступает из общего контроллера. Первое чтение сессии задаёт базовое значение, увеличение зажигает новые сегменты и увеличивает индикатор на 2,8 с; уменьшение не проигрывает загорание. Временные состояния не записываются в сохранение.

Портал привязан к подтверждённому `andrey-teleport-to-arena`: 1,25 с до смены URL под непрозрачным слоем, 2,8 с до открытия арены. Один переход даже при пропуске/Escape. Первый бой запускается существующим движком. При reduced motion — 500 мс затемнения без вращения (ветка проверена по коду; системный режим в браузере отдельно не переключался).

Проверки во встроенном браузере на отдельном origin4185:
- Появление Нетака → признание → перенос. Открывается портал, затем арена с первым боем: Нетак 80 HP, три колбы по 10 HP, раунд 1, инициатива готова.
- «Шаг назад» из боя возвращает к признанию на вилле; перенос снова доступен.
- «Пропустить» и Escape закрывают портал и приводят на арену; перезагрузка активного боя не повторяет портал.
- Портал просмотрен на 1280×800 и 1024×768; UI остаётся под блокирующим слоем.
- После «Идти с Kreed» счётчик меняется 0→1 при переходе на `post-kreed-route` (в тестовом сохранении пройдена только эта веха).
- При ручном выключении вехи счётчик уменьшается без эффекта. При повторном включении зафиксированы `announce`, scale≈1,46 и яркое новое деление; контрольный скриншот показывает увеличение и расходящийся ореол.
- После полной перезагрузки счётчик 1/5 имеет animationName=none. Горизонтального переполнения и ошибок/предупреждений консоли нет.

Автотесты добавлены в `test-gm-console.ts`: начальная загрузка, повтор того же состояния, увеличение сразу на несколько делений, отмена, повторное получение, новая сессия. 30/30 regression suites, typecheck, build и build:pages прошли. Изменения визуальные, формат журнала и сохранений прежний. Исходное прохождение на 4183 не использовалось для тестов.
