# Рабочие арты Пенисуэлы

Эта папка содержит локальные рабочие генерации кампании и исключена из Git, кроме этого README. Файлы здесь не являются каноническими и не должны использоваться приложением. Утверждённые варианты перечисляются в `art-plan.json`, публикуются в `assets/concepts/campaigns/penisuela/` и регистрируются в `assets/concepts/manifest.json` через `publish-dnd-campaign-assets`.

Личные фотографии и пути к ним сюда не копируются.
