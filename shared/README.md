# Общие контракты

[`api/openapi.yaml`](api/openapi.yaml) — источник истины для HTTP-контракта между фронтендом и Go-бэкендом. Здесь хранятся спецификации, а не общий TypeScript-код. Создаваемые по спецификации файлы должны находиться внутри соответствующего проекта.

[`advisor/guide.json`](advisor/guide.json) — общий публичный каталог коротких подсказок на семи этапах конструктора. Это данные интерфейса, без игрового лора, формул и секретов мастера. API отдаёт каталог через `GET /creator/advisor`; фронтенд включает ту же копию в сборку для мгновенного показа подсказок. Транспортные типы описаны в OpenAPI, Go и TypeScript остаются в своих проектах.

[`advisor/persona.md`](advisor/persona.md) задаёт голос совы: весёлый пернатый сообщник, короткие реплики на «ты», добрые шутки и уважение к выбору игрока. Сейчас этот характер отражён в бесплатных подсказках; файл станет инструкцией агента при подключении AI Studio.

`api/proposals/` содержит будущие изменения контракта: `draft` до утверждения и `approved-design` после него, до реализации в API. [Навыки конструктора v1](api/proposals/character-abilities-v1.yaml) утверждены 30 сентября 2026 года вместе с [правилами и примерами](../docs/architecture/character-abilities-v1/gameplay-notes.md). Канонические числа находятся в [content/character-abilities.json](../content/character-abilities.json); схемы перенесены в основной контракт при серверной реализации v2. Файл в proposals теперь помечен `implemented` и сохраняет первоначальный дизайн; актуальные входы и ответы описывает `api/openapi.yaml`.

Советник: `api/openapi.yaml` описывает отдельные сессии диалога и бюджет,
`advisor/persona.md` — голос совы. Снимок анкеты передаётся на один вызов,
токен сессии не является авторизацией игрока. Платный режим включается отдельно.
