# Кадровая анимация Советника

Подготовлено 2 октября 2026. Статус — визуальный вариант одобрен пользователем; функциональное обновление готовится к публикации.

## Устройство

Из `work-pets:create-pet` взят принцип: отдельная связная последовательность
для каждого состояния, постоянные масштаб/опора и длительность каждого кадра.
Скилл предназначен для ChatGPT Work, поэтому его Library, upload и активация
питомца здесь не используются. Формат нашего сервиса отличается от Pets v2:
персонаж сидит на ветке, направления бега и шестнадцать направлений взгляда не нужны.

Все новые позы созданы встроенным `image_gen`, по `reference-owl.png`.
Неудачный жест со сменой стороны крыла и тесный шестикадровый покой отклонены.
В выбранном жесте двигается одно крыло справа на экране; обе лапы остаются на ветке.
В покое меняются грудка, плечи и веки. Остальные состояния меняют голову и клюв.

| Состояние | Кадры | Событие | Поведение |
| --- | ---: | --- | --- |
| Покой | 4 | Нет активного события | Дыхание, моргание; цикл 4,22 с |
| Размышление | 4 | Запрос выполняется | Наклон головы и внимательный взгляд; цикл 1,88 с |
| Ответ | 4 | Пришла новая реплика | Клюв и кивок; цикл 650 мс во время появления ответа |
| Приветствие / радость | 6 | Первое появление, применение наброска | Одно крыло раскрывается и складывается; 1,12 с, затем покой |
| Ошибка | 4 | Ошибка чата | Короткая озадаченная реакция; 1,28 с, затем покой |
| Наведение | 4 | Курсор или клавиатурный фокус | Любопытный наклон; 1,48 с один раз, затем покой |
| Клик | 4 | Клик, Enter или Space по персонажу | Перья и подмигивание; 1,24 с один раз, затем покой |

`advisor-sprites-v1.webp`: 4608×4928, сетка 6×7, растровая ячейка 768×704,
30 кадров, около 2 МиБ. Плотность 2×: логическая ячейка остаётся 384×352,
координаты и длительности кадров не меняются. Пустые ячейки прозрачны. Генератор подготовил
позы без ветки; альфа сохранена при механической сборке.
`advisor-branch-v1.webp` содержит одну неподвижную ветку в координатах ячейки.
Оба ассета используются на странице и в модальном окне.
Область отображения 304×300 одинакова для всех кадров, включая раскрытое крыло.
Она ограничена отдельным SVG clipPath, чтобы соседние строки не попадали
в свободное пространство при `preserveAspectRatio="meet"`.

Таймер обновляет только компонент Советника на границах кадров.
При уходе со страницы, скрытии вкладки и `prefers-reduced-motion` движение
останавливается. При ошибке загрузки спрайта остаётся исходный статичный арт.
Пауза reduced motion предусмотрена в коде; изменение системной настройки
в этой проверке не выполнялось.

## Подготовка ассета

Прозрачность получена из генератора. Маски для удаления фона, chroma key,
деспилл и дорисовка пикселей не применялись.
Механическая сборка обнаруживает группы поз по прозрачным промежуткам,
использует один масштаб на состояние и совмещает неподвижную область лап.
Не подгоняет каждый кадр по отдельному размеру. Измерительный порог альфа
используется только для геометрии; исходный альфа-канал не переписывается.

Повторная сборка при наличии исходных полос `idle.png`, `thinking.png`,
`speaking.png`, `greeting.png`, `error.png`, `curious.png`, `playful.png`
без ветки и отдельного `branch.png`:

```bash
python3 frontend/scripts/pack-advisor-sprites.py \
  --source-dir /path/to/generated-strips \
  --output-dir frontend/assets/concepts/ui/character-creator/advisor
```

Нужны Pillow и NumPy. Исходные генерации не входят в зависимости приложения;
их SHA-256 и геометрия принятых кадров записаны в `sprite-layout.json`.
Новый пакет не добавлялся в frontend. Принятые промпты — `prompts.json`.

## Приёмка

Во встроенном браузере проверены 1280×720 и 1024×768, страница и большой чат:
ожидание запроса, применение/отмена наброска, жест крылом и переход в покой,
ошибка запроса. Проверка использовала локальные ответы API без AI Studio
и записи в production-БД. Отсутствуют горизонтальный overflow и ошибки JS.
Обнаруженный выход соседнего кадра в свободное место SVG исправлен clipPath.

`states-preview.webp` — анимированное превью из конечных WebP с тем же порядком
слоёв, что в UI. `ui-1024.jpg` и `ui-1280.jpg` — контрольные кадры страницы.

## Исправление опоры и хвоста

После замечания пользователя обнаружено различие веток между состояниями.
Позы перегенерированы без ветки, а сама ветка вынесена в один статичный ассет.
SVG больше не перемещает всю область просмотра: движется только изображение
выбранного кадра внутри постоянного clipPath.

Порядок слоёв: персонаж с хвостом → ветка → лапы того же кадра. Область лап
ограничена SVG clipPath, поэтому ветка закрывает хвост, а когти остаются перед ней.
Это порядок отрисовки UI; фон и альфа файлов программно не удалялись.
Лапы и ветка совмещены по высоте без зазора. Пять состояний проверены на
временном локальном экране; также проверены страница и большой чат.

## Реакции на игрока

Персонаж — нативная кнопка с доступным именем. Наведение и клавиатурный фокус
проигрывают любопытную реакцию один раз. Клик/Enter/Space запускают подмигивание;
новый клик перезапускает только эту короткую реакцию. После неё сохраняется покой
даже при оставшемся курсоре. Следующее наведение срабатывает после выхода курсора.
Активные состояния ответа/ожидания сохраняют приоритет над наведением.

Первый вариант после клика возвращал зацикленное наведение; этот дефект исправлен.
Повторное приветствие после прерванного кликом первого появления также исключено.
В модалке расширена колонка персонажа, уменьшены пустые поля внутри SVG,
добавлен мягкий фон за персонажем. На странице хвостик подсказки направлен к
голове через локальную переменную `--advisor-tail-right: 65%`.

## Правая колонка и инструменты

Пользователь отклонил сужение до 286/260 px. Итоговая колонка снова шире,
с естественной высотой, без растяжения персонажа на весь экран. Арт ограничен
160–210 px в зависимости от высоты окна. Под кнопкой чата находятся четыре
поручения: имя/история, раса/класс, навык и герой с нуля. Они открывают модалку
с редактируемой репликой и не отправляют её автоматически.
Семь этапов занимают общую строку над формой и Советником.

В большом чате тот же персонаж и шкала запаса; ниже отдельная прокрутка
инструментов: предложения раздела/всего героя, портрет, иконка навыка и полный
набор. Справа независимо прокручивается диалог, поле ввода остаётся снизу.
Готовый набор сохраняется при закрытии чата, платная цепочка прекращается после
текущего вызова. Просмотр и применение остаются действиями игрока.

Контрольные размеры новой функциональной проверки: 1024×768 и 1280×720,
без горизонтального overflow. `ui-tools-1024.png`, `ui-tools-1280.png` и
`dialog-tools-1024.png`, `dialog-tools-1280.png` — итоговые снимки. Прежние
`ui-1024.jpg`/`ui-1280.jpg` относятся к отклонённому узкому варианту.

Тест границ кадров, циклов и возврата в покой подготовлен в
`frontend/scripts/test-advisor-animation.ts` для существующего regression CI.
Локальные сборки, typecheck и автоматические тесты не запускались.
Мобильный UX Советника отложен по решению пользователя.
Новых фактов лора и игровых чисел нет. Ассеты зарегистрированы как reference;
код и новые облачные инструменты ещё не опубликованы.
