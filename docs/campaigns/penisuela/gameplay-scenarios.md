# Сценарные проверки текущей Пенисуэлы

Дата: 14 сентября 2026. Статус: **38/38 наборов прошли** командой `npm run test:regression`.

| Область | Проверяемые сценарии |
|---|---|
| Общая сессия | стартовый снимок, физические и цифровые броски, характеристики, журнал, сериализация/replay, расход предметов и все scopes |
| Гостиница | аудиенция Pussy Sultan, скипетр, три VIP-стражника по 56 HP, реквизиторская, пропуска, независимые направления хаба |
| Музыкальный пульт | первая верная попытка, каждый из 11 неверных треков, повторные волны, блокировка повторного ответа, отмена, награда, проигрыш и возврат; остановка и переключение медиа |
| Бой и мастер | инициатива, ход/раунд, атака/урон/криты, состояния, контроль, лечение, ручные HP/AC/инвентарь, предложения NPC и явное решение мастера |
| Отдых | полное HP, восстановление зарядов имеющихся предметов и location-навыков, сохранение расхода campaign-навыков, одноразовая карточка, отмена и сохранение |
| Оливия и поздний путь | возвращение за Станисом, стол и голосование, награда/отказ, бой Егорика, испытания тоннеля, Grey Wiese, спальня |
| Нетак и финалы | колбы, навыки освобождённых гостей, навыки эльфа и дракона, две фазы без лечения между ними, победа/поражение, свадьба и общая награда |
| Навигация и содержание | шесть блоков, контрольные точки и откаты, hotspot-координаты, рассказчик, активные URL, исключение старых сцен и точные копии канонических данных |

Старое ограничение «ровно два неверных трека» удалено. Инварианты игры сохранены: единственный верный ответ, не менее двух разных неверных вариантов для проверки повторных попыток и одна новая волна на каждый ещё не отклонённый неверный ответ.

Расчёт накопленного баланса — отдельная проверка, а не часть счётчика 38/38. Он использует реальные команды и reducer с пассивками всех пяти героев. Для нового полного маршрута с двумя ошибками отдых применяется один раз после второй волны. Параметры и результаты: [balance-review.md](balance-review.md).

Набор содержит и проверки сохранённого старого движка финала; их прохождение не означает, что старые сцены доступны в текущей игре. Состав текущего маршрута проверяет `validate-penisuela-current-release.mjs`.

Это автоматические проверки. Фактические клики, компоновка и восстановление React после refresh относятся к датированным браузерным отчётам, перечисленным в [release-verification.md](release-verification.md). Старый отчёт 10/10 и 210 утверждений сохранён в [архиве](history/2026-09-14-before-tuning/gameplay-scenarios.md).
