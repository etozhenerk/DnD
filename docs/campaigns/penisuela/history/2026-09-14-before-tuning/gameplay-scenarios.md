# Сценарные тесты кампании «Мальчишник конца света»

Статус: `passed`.

Дата контрольного прогона: 24 августа 2026 года.

Основной сценарный раннер: `scripts/test-penisuela-runtime.mjs`. Он загружает production TypeScript-модули через Vite `ssrLoadModule`, исполняет чистые команды и reducer независимо от React и не содержит собственной реализации бросков, боя, восстановления журнала, выбора NPC или правил финального босса.

## Итог

- 10 из 10 production-runtime сценариев пройдены;
- 210 из 210 утверждений пройдены;
- расхождений с каноническими JSON не обнаружено;
- блокеров для следующей браузерной приёмки нет.

## Границы чистого сценарного прогона

Раннер доказывает production-модели, команды, reducer, журнал и их детерминированные состояния. Он намеренно не подменяет браузерную приёмку.

- Реальный адаптер `localStorage`, восстановление после перезагрузки страницы и продолжение через React проверяются в браузере; здесь доказан его чистый контракт `serialize → parse → replay`.
- Сборка событий story action, диалогового эффекта и обычного fail-forward находится внутри React hook. В раннере используются точные канонические event fixtures, а production reducer проверяет их результат и атомарный откат; нажатия соответствующих кнопок проверяются отдельно.
- Визуальная доступность действий, маршруты, консоль браузера, фокус, адаптивность и сохранение состояния между реальными переходами относятся к `release-verification.md`.
- Случайность не проверяется статистически: цифровой генератор проверен на допустимых границах, а все воспроизводимые сценарии используют явные значения кубиков.

Непроверенных ручных механических эффектов внутри чистой модели нет. Оставшиеся пункты — UI/browser integration, а не блокеры rules engine.
