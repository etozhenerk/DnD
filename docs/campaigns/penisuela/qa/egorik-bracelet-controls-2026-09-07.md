- В `assets/concepts/manifest.json` опубликованы утверждённые `scenes/egorik-bungalow-conversation.png` и `scenes/egorik-bracelet-truth-closeup.png`.

Для нового описания запрещены имя NPC, название сцены и дополнительная разметка. Правило закреплено в AGENTS.md и implement-dnd-campaign-ui/SKILL.md. ## Результаты

- Реальный бой пройден через штатные ручные d20 и урон: победа открывает общий кадр, правды о женихе и кнопки перехода ещё нет.
- «Показать браслет» открывает крупный план и выдаёт правду курьера. В панели остаётся «Общая сцена».
- Reload сохраняет крупный план. Возврат сохраняет сведения и показывает «Идти к Егору Криду».
- Три последовательных цикла показа/возврата выполнены; переключатели не блокируются после первого использования.
- Undo возврата восстанавливает крупный план; undo первого раскрытия возвращает исходный разговор без правды.
- Кнопка перехода открывает `groom-tunnel`. Сюжетное уточнение: конверт передан Криду у входа в тоннель; он ушёл под сцену к комнате подготовки.
- Встроенный браузер: скриншоты 1280×720 и 1024×768; лица и буква «Е» видимы над панелью. На 1024 document scrollWidth = clientWidth, изображения загружены. После поправки заголовка проверены оба ракурса и сворачивание панели.
- Чистая вкладка после реализации: errors/warnings отсутствуют. В прежней вкладке сохранилось предупреждение React при горячей замене списка useEffect; на чистой загрузке не воспроизводится.
- `npm run validate:penisuela-playable`: 728 проверок PASS.
- `node scripts/test-egorik-bungalow.mjs`: PASS, включая отложенную выдачу улик, условия маршрута, отмену и восстановление журнала.
- `npm run build` (включает typecheck): PASS после правки общего заголовка. `npm run build:pages`: PASS для реализации переключений. Предупреждение о крупных чанках остаётся прежним.
- `jq empty` затронутых JSON и `git diff --check`: PASS.

Поражение проверялось интерактивно в предыдущей приёмке боя; новая последовательность после поражения проверена по каноническим действиям, отдельное повторное прохождение поражения не выполнялось.
