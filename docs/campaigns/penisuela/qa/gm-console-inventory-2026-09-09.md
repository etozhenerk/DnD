# GM-консоль и общая сумка — 9 сентября 2026

Область: управление кампанией Пенисуэлы. Это проверка изменённой GM-консоли и инвентаря, а не новое ручное прохождение всех сцен.

## Реализовано

- Шесть разделов: герои с утверждёнными аватарками, инвентарь, бой, сцены, прогресс, журнал. Редактор реплик удалён. Песочница боя и отключение видео навыков сохранены.
- Каталог общей сумки содержит 13 встречающихся в кампании предметов; личная экипировка исключена. Выдача, количество, заряды и удаление доступны мастеру. Выдача сама по себе не завершает сюжетный квест.
- Исправлена синхронизация ручного удаления/отмены выдачи с видимой сумкой. Лимит духов сохраняется: три заряда на кампанию.
- Шесть недостающих иконок созданы встроенным ImageGen. Духи переработаны по замечанию пользователя: версия v2 с крылатой золотой крышкой и крупным логотипом GREY WIESE. Промпты: `../gm-inventory-icons.json`.
- Иконки используют contain без увеличения. Hover и keyboard focus ограничены ячейкой; подсветка внутренняя, наружное масштабирование удалено.

## Проверки

- Автотесты: `npm run test:regression` — 30/30, включая валидацию GM-полей, отмену, каталог без личных вещей, ручную выдачу/удаление духов, сохранение двух зарядов из трёх.
- `npm run build` (включает typecheck) и `npm run build:pages` проходят. Vite предупреждает о размере крупных чанков.
- JSON читаются через jq; все 13/13 предметов имеют существующие и зарегистрированные иконки. ID предметов и UI-ассетов уникальны.
- Встроенный браузер, отдельное тестовое сохранение, 1280×800 и 1024×768: изображения загружены; горизонтального переполнения нет. Скриншоты обоих размеров просмотрены в ходе проверки.
- GM: изменение HP, maxHP с ограничением текущего HP, AC, атаки, временного бонуса и состояния; переключение героя не переносит его значения другому; отмена и перезагрузка; читаемые имена в журнале.
- GM: переход между сценами с отменой, включая возврат в `closed-bar?view=stas`; порядок инициативы, текущий участник и раунд; изменение HP врага с отменой. Песочница отделена от сохранения кампании; настройка видео сохраняется.
- Общая сумка: духи занимают первую свободную ячейку перед двумя существующими предметами; удаление немедленно убирает их; отмена возвращает предмет и 2 заряда. После перезагрузки заряды сохраняются.
- Все шесть новых иконок одновременно показаны в сумке; осмотр каждой открывается и закрывается Escape. Реальный hover проверен на духах при обоих размерах: wrapper transform=none, overflow=hidden, inset-подсветка. Обводка не выходит за слот.
- В консоли браузера нет ошибок или предупреждений.
