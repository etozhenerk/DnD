# Хроники Восьми Земель

Репозиторий сервиса авторских D&D-кампаний. Сейчас игрокам доступен статический фронтенд; Go-бэкенд создан как основа для конструктора героев и будущих серверных функций.

| Каталог | Назначение |
| --- | --- |
| [`frontend/`](frontend/README.md) | React-приложение, ассеты, сборка и фронтовые проверки |
| [`backend/`](backend/README.md) | Go API; пока только проверка доступности |
| [`shared/`](shared/README.md) | Общая YAML-спецификация HTTP API |
| [`content/`](content/README.md) | Канонический лор, правила, герои и кампании |
| [`skills/`](skills/) | Общие локальные инструкции для работы с проектом |
| [`docs/`](docs/) | Продуктовые планы, сценарная работа и исследования |
| [`infra/`](infra/) | Конфигурации экспериментальных LLM-ВМ |

Фронтенд запускается из своего каталога:

```bash
cd frontend
npm ci
npm run dev
```

Бэкенд запускается отдельно:

```bash
cd backend
go test ./...
go run ./cmd/api
```

Деплой фронтенда из `main` выполняют GitHub Actions; Go API пока только собирается и проверяется. Подробности запуска и архитектуры находятся в README соответствующих каталогов.
