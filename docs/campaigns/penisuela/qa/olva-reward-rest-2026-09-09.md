# Награда Олвы и карточка отдыха

## Изменение по запросу пользователя

После любого из трёх вердиктов показывается только исход Стаса и Полины. Затем отдельное действие открывает благодарность Олвы. Получение награды добавляет ключ-карту `guest-bungalow-pass` и карточку отдыха `olva-timeout` в одну команду журнала. Следующее действие возвращает на `guest-bungalows`.

Карточка заменяет прежний разговорный тайм-аут: один заряд на кампанию, вне боя по 1d8 HP каждому герою, ограничение максимумом HP, восстановление ресурсов локации. Расход и лечение отменяются вместе. Текущий интерфейс применения — клик по карточке в общей сумке; см. дополнение ниже. Запись журнала показывает фактическое лечение и выпавший d8 отдельно.

Принятие просьбы больше не выдаёт ключи заранее. Отказ сохраняет бесплатный доступ к Егорику. Старые сохранения с уже полученной карточкой сохраняют её остаток: новый экран не пополняет заряды и не дублирует предметы. Stable ID и формат сохранений не изменены.

## Арт

- v1 отклонён пользователем из-за руки, v2 — из-за артефактов после редактирования.
- v3 создан с нуля, но генератор добавил рамку интерфейса; не подключался.
- В игре используется `assets/concepts/campaigns/penisuela/scenes/olva-reward-handoff-v4.png`, созданный с нуля через встроенный ImageGen по исходному утверждённому облику Олвы. Карточки лежат на столе, руки не держат их крупным планом. Промпт и история находятся в `art-plan.json` → `olvaRewardHandoff`.
- Отдельное одобрение v4 пользователем пока не получено; запись manifest имеет статус generated. Изображение подключено для оценки, без утверждения за пользователя.

- «Шаг назад» проверен последовательно: отмена передачи убирает обе новые награды; следующий шаг возвращает к исходу; следующий — к прежним пяти голосам. Перезагрузка на благодарности сохраняет этап.
- Карточка в UI: Бубсильда 20 → 21 HP при выпавшем 1, заряд 1 → 0, повторное применение заблокировано. Отмена возвращает 20 HP и один заряд.

## Дополнение: применение из общей сумки

Карточка открывает общий `SceneDecisionModal` с пятью аватарками, HP, полями d8, отдельными бросками и «Бросить за всех». Служебные пояснения и подпись «Доступные решения» убраны. До «Принять» броски и ручной ввод не изменяют игру. Подтверждение одной командой расходует заряд, лечит, удаляет карточку и отмечает использование. Корона «Шаг назад» возвращает предмет и предыдущее HP. Повторная выдача старого сюжетного вознаграждения не пополняет использованную карточку.

Проверка во встроенном браузере на 4183, отдельно от исходного прохождения:
- Групповой цифровой бросок дал 1, 1, 3, 4, 7 и заполнил пять ячеек; отдельный бросок Бубсильды заменил только её результат на 5.
- Отмена после бросков сохранила карточку и HP. После повторного открытия поля пустые.
- Ручное 9 не разрешает подтверждение; пять значений 8 дают предпросмотр. Бубсильда с 20/38 получила 28/38 только после «Принять», остальные остались на максимуме.
- Карточка исчезла из сумки, отсутствие сохранилось после перезагрузки. Корона «Шаг назад» вернула карточку и 20/38 HP. Тестовый урон затем отменён через GM.
- Окно просмотрено при 1024×768 и 1280×800: пять портретов и кнопки помещаются, горизонтального переполнения нет.
- Первое открытие встретило устаревший Vite URL динамического модуля кубиков; обновление страницы загрузило актуальный модуль, после чего оба вида бросков проверены успешно.

Дополнительно на `guest-bungalows`: клик открывает то же окно; Escape после ручного ввода сохраняет карточку, повторное открытие очищает поля. Новых ошибок консоли после обновления не появилось.

Автоматически: 30/30 regression suites, typecheck, build, build:pages; тесты дополнены проверками ручного ввода, удаления предмета и атомарной отмены. Новое правило по запросу пользователя: карточка исчезает после подтверждённого применения. Стабильные ID и формат сохранений не менялись.
