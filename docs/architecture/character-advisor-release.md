# Публикация полного Советника

Статус на 2 октября 2026: UI и публикация одобрены. Миграция 000008 применена,
право runtime на генерацию изображений и lifecycle для временных файлов настроены.
Код опубликован через CI. После сообщений об ошибках применена согласованная миграция
000009 для продолжения диалога; локальные сборки и тесты не запускались.

## Согласованный набор действий

1. Применить `backend/migrations/000008_advisor_tools.up.sql` от владельца БД
   `dnd` в кластере `c9qdojtaghn6i5h4vq4o`, проверить версию и три новых столбца.
   Не выдавать новых SQL-прав; приложение не применяет миграции автоматически.
2. Выдать runtime `dnd-api-runtime` (`aje99fiebjm3lg4k2fpk`) роль
   `ai.imageGeneration.user` на каталог `b1g8siv8ve2si1qp04nm`.
   Это разрешает платные генерации изображения в каталоге; IAM остаётся на бэкенде.
3. Прочитать действующие lifecycle rules закрытого бакета
   `dnd-character-media-b1g8siv8ve2si1qp04nm`, добавить правило из
   `infra/backend/advisor-media-lifecycle.json`, сохранив прочие правила.
   Оно удаляет только временные `advisor/` результаты через два дня.
   Сохранённые изображения персонажей под `characters/` не затрагиваются.
4. Опубликовать подготовленные frontend/backend/контракт/документацию в `main`.
   Дождаться backend race-тестов, SQL/HTTP/OpenAPI-проверок, regression frontend,
   typecheck и обеих сборок через существующие CI. Новых frontend quality gates нет.
5. Установить GitHub Actions variable `DND_ADVISOR_IMAGES_ENABLED=true`.
   Workflow задаёт контейнеру время выполнения 120 с; CPU/RAM и Gateway прежние.
   После включения опубликовать успешную ревизию и проверить capabilities.
6. Проверить живые короткий чат, заполнение, один портрет и одну иконку с общим
   лимитом проверки **20 ₽**. Повторить те же UUID, сверить отсутствие дополнительных
   расходов; проверить отказ чужому токену, применение и последующее чтение медиа.
   Не сохранять тестового героя в production без необходимости.

Пределы сервиса остаются **200 ₽ на сессию создания**, **10 000 ₽/мес**.
Комментарии, текст и изображения учитываются вместе. Без авторизации ограничение
привязано к сессии, не к человеку. Нового ключа пользователя или публичного бакета нет.

## Порядок и остановка

Миграция аддитивная и должна предшествовать новой ревизии API. Первая ревизия
проверяется с выключенными изображениями; включение инструмента выполняется после
CI и IAM. Не удалять столбцы при возврате к предыдущей ревизии.
`DND_ADVISOR_IMAGES_ENABLED=false` закрывает генерацию и приватное чтение новых
результатов; `DND_ADVISOR_CHAT_ENABLED=false` отключает весь платный Советник.
Проверить фактические capabilities после публикации ревизии.

## Дополнение: визуальные промпты и сообщения

Подготовлен отдельный компоновщик промпта для Alice AI ART через DeepSeek:
анкета/пожелания/фиксированный стиль → структурированный JSON → проверенный
промпт до 500 символов → изображение. Резерв и окончательные расходы включают
оба этапа. Миграций и новых IAM-прав для этого дополнения не требуется.

Клиент направляет явную просьбу нарисовать портрет/иконку сразу в этот сценарий,
не показывает служебные запросы как сообщения игрока и выбирает раздел по этапу.
Голос Советника сокращён и дополнен разговорными примерами. Выделение урона/лечения
и контраст расы/класса исправлены. Результаты нового CI и живой проверки будут
зафиксированы после публикации.
