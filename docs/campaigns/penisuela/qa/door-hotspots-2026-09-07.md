# Клики по дверям: целевая приёмка 7 сентября 2026

Статус: passed. Запрос пользователя: двери на артах должны открываться по клику с существующей подсветкой во всех сценах.

## Область изменения

- `BedroomRevealAdventure`: клик по закрытой двери раскрывает спальню, вместо отдельной кнопки короны.
- `GraywiseDoorAdventure`: закрытая дверь запускает проверку группы, после отказа — просьбу к Егору; открытый проём ведёт в дом. Кнопка «Попросить Егора» также сохранена в панели мастера согласно предыдущему запросу.
- `GroomTunnelAdventure`: кликабельны подход к двери после декораций, дверь для действия Линды, открытый проём за Линдой и дверь к Криду после освобождения тамбура. Условия и расход умения остаются в существующих обработчиках.
- Общий `SceneHotspotLayer` получил необязательную привязку координат к изображению через `useSceneHotspotFrame` и `getFittedImageRect`. Она учитывает contain/cover и размеры окна. Существующие вызовы сохраняют прежнюю систему координат. Hover/focus CSS общий и не менялся.
- Аудит `HotelOverloadSearchAdventure`, `HotelGalleryAdventure`, `ClosedBarAdventure`, `GuestBungalowsAdventure` и пространственных действий `LateStoryAdventure` подтвердил существующие клики по сюжетным дверям/проходам. Диалоговые и боевые GM-действия не являются кликами по двери.
- Правило закреплено в `AGENTS.md` и `skills/implement-dnd-campaign-ui/SKILL.md`; мастерский гайд, gameplay prompt, script, art-plan и implementation-plan синхронизированы.

## Проверка в браузере

Встроенный браузер, dev-сервер 4176, viewport 1280×800 и 1024×768.

- Спальня: клик мышью и Enter открывают утверждённый арт; отмена возвращает закрытую дверь. Подсветка совпадает с дверью на обоих размерах.
- Grey Wiese: клик открывает общую проверку DC 12. Физический результат 8 + 3 оставляет дверь закрытой. Следующий клик «Попросить Егора» открывает NPC-проверку DC 8; результат 8 открывает дверь. Клик по проёму переводит в спальню.
- Тоннель: до преодоления декораций клика по дальней двери нет. После действия Бубсильды доступен подход; закрытая дверь применяет действие Линды; проход ведёт в заваленный тамбур. Пока тележка не убрана, вход к Криду недоступен. После принятия другого способа убрать тележку клик по дальней двери ведёт в убежище Крида.
- Геометрия подсветки проверена скриншотами встроенного браузера; focus-visible активирован клавиатурой, opacity общего свечения равна 1. Наведение курсора отдельно не автоматизировалось: hover использует тот же существующий CSS-эффект.
- Горизонтального переполнения на проверенных размерах нет. Console errors/warnings отсутствуют. Тестовые команды последовательно отменены; вкладка оставлена у закрытой двери спальни.
