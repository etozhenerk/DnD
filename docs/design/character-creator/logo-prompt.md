# Логотип шапки

Локальный визуальный вариант, ожидающий одобрения. Не добавляет сущностей в канон.

- Инструмент: встроенный `imagegen`, режим редактирования с настоящим прозрачным фоном.
- Референс: верхний левый угол [01-appearance.png](01-appearance.png).
- Файл: `frontend/assets/concepts/ui/character-creator/chronicles-logo.png`, 2172 × 724 px, PNG с альфа-каналом непосредственно из генератора. Пиксели не обрабатывались; приложение сохраняет пропорции изображения.

## Финальный промпт

Use case: precise-object-edit / logo-brand. Edit target: the provided fantasy game interface mockup. Derive ONLY the top-left brand logo into a standalone transparent PNG website header asset. Preserve the visual style of that TOP LEFT logo: dark carved walnut plaque, aged warm bronze ornamental edging, left circular sun compass medallion with eight main rays, pale gold serif Cyrillic wordmark on two lines. The wordmark must read exactly: first line «Хроники», second line «Восьми Земель». Make the second line slightly larger and text very clear at small website header sizes. The sun and lettering are a SINGLE coherent finished logo plaque, all lettering contained inside the plaque. Horizontal compact lockup, approx 4:1 visible artwork ratio, sun about same height as plaque, balanced silhouette, controlled thin carved filigree only at edge, subtle material depth like the reference. Straight-on orthographic UI artwork, no perspective. Use nearly entire canvas width, with minimal transparent padding. TRUE alpha transparency outside the badge. Do NOT generate a screenshot, UI, other navigation, forest, people, owl, dice, extra words, background, shadow rectangle or watermark. Do not produce a modern vector compass icon. Result should look like the beautiful top-left asset in the reference, meticulously painted bronze and dark wood fantasy RPG branding.
